Portable energy storage that can be placed on the ground and used as a temporary power source. 
When broken, the dropped item will retain its charge.

The fill level can be measured with a comparator. A redstone signal to the block stops it from outputting energy.

Default energy capacity is 1M EU. Accepts energy from all sides through a 🟢 *green port* and can only output 
through the single 🔴 *red port*.

Addons can increase capacity or throughput. Throughput statistics can be viewed in the machine GUI. The output limit slider in the screen allows
you to set a custom output limit if you want to limit how much EU a target machine / network should get.
