这个模拟有多还原？

这里的每刻处理顺序是固定的：燃料棒 → 热量管道 → 吸收器 → 散热口 → 回收口。 而游戏遍历的是 HashMap，因此同一刻内各组件的处理顺序并不固定，结果每刻可能相差几点 K。 稳态数值是一致的；请把它当作设计工具，而不是逐位精确的复刻。

运行时假设燃料与冷却剂无限供应：每个燃料口都是满的、每个吸收器都有冷却剂， 这对应一个供应充足的反应堆。

每层内部结构完全相同（游戏本身也这样要求）。能量、燃料与冷却剂消耗都随堆叠高度缩放， 散热则不随高度缩放。
